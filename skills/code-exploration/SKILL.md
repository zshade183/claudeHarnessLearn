# 代码阅读流程

当用户要求解释项目结构、模块职责或调用流程时，按以下步骤执行：

1. 使用 glob 找到相关文件。
2. 使用 read_file 阅读入口、调用方和被调用方。
3. 根据实际导入和函数调用追踪执行过程。
4. 区分源码中已实现的行为与自己的推测。
5. 只阅读和解释，不修改文件。

# 输出要求

回答包含以下三部分：

- 相关文件：列出实际阅读过的文件及其职责。
- 调用路径：按执行顺序说明函数之间的调用关系。
- 结论与限制：回答用户问题，并说明尚未确认的部分。

涉及具体实现时，注明对应的文件路径和函数名。
